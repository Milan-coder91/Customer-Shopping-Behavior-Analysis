# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

This project is an end-to-end **Data Analytics project** based on Customer Shopping Behavior data.

The objective of this project is to analyze customer purchasing patterns and extract meaningful insights using **Python, SQL, and Power BI**.

The project follows a complete data analytics workflow:

**Raw Data → Data Cleaning → Data Analysis → Data Visualization**

---

## 🛠️ Tools & Technologies

* 🐍 **Python** – Data Cleaning and Preprocessing
* 🐼 **Pandas** – Data Manipulation and Analysis
* 🗄️ **SQL / PostgreSQL** – Business Analysis and SQL Queries
* 📊 **Power BI** – Interactive Dashboard and Data Visualization

---

## 🔄 Project Workflow

### 1️⃣ Data Cleaning and Preprocessing – Python

The dataset was processed using Python and Pandas.

Key tasks performed:

* Loaded and explored the dataset
* Checked for missing values
* Handled missing values in the Review Rating column
* Used category-wise median imputation
* Renamed columns using snake_case
* Created an Age Group feature
* Converted purchase frequency into numerical values
* Removed unnecessary or redundant columns
* Prepared the cleaned data for further analysis

---

### 2️⃣ Data Analysis – SQL

SQL queries were used to answer different business questions, including:

* Revenue generated by male vs. female customers
* Customers who used discounts and spent above the average purchase amount
* Top products based on average review ratings
* Comparison of Standard and Express shipping purchase amounts
* Spending behavior of subscribers vs. non-subscribers
* Products with the highest discount usage
* Customer segmentation into New, Returning, and Loyal customers
* Top purchased products within each category
* Analysis of repeat buyers and subscription behavior
* Revenue contribution by different age groups

---

### 3️⃣ Data Visualization – Power BI

An interactive Power BI dashboard was created to visualize customer shopping behavior and business insights.

The dashboard focuses on:

* 📈 Customer purchase analysis
* 💰 Revenue analysis
* 👥 Gender and age group analysis
* 🛍️ Product and category performance
* 🎯 Subscription analysis
* 🏷️ Discount behavior
* 📊 Interactive visualizations and filters
